# Review and repair before release

Read `prompts/build.md`. Run the app and its documented checks; inspect the actual downloaded PPTX, offline HTML and PNG ZIP. Use a fresh deck with Unicode, long text, replaced portrait images, notes and reordered slides. Verify PPTX open/edit/re-export and its import report, autosave, JSON reopen, document-specific undo/redo, pending text during word selection, delayed file opens, keyboard editing and every export button. Compare editor/presentation/export visuals, inspect all template layouts, and verify native PowerPoint objects. Fix failures and rerun affected checks. Report Google Slides and desktop PowerPoint checks as unverified unless actually performed. Review every publishable file for secrets, personal paths, copied assets and unrelated material. Keep docs factual and short. Leave changes uncommitted; do not push or deploy.
