# Template references

These are original editable layouts inspired by presentation conventions, not reproductions of reference decks.

| Public reference | Observed composition | Application |
| --- | --- | --- |
| [Linear pitch deck](https://deck.gallery/linear-pitch-deck/) | Dark cover, short central message, generous negative space | Bold Studio uses one dominant statement, strong contrast and one accent |
| [SPACE10 exhibition catalogue](https://deck.gallery/space10-exhibition-catalogue/) | Large stacked heading with an image-led cover | Editorial uses a strong hierarchy and purposeful image areas |
| [DEPT impact report](https://deck.gallery/dept-impact-report-2023/) | Public listing describes a long report organized around topics and metrics | Comparison, metrics and timeline layouts provide a consistent report structure |

The Linear and SPACE10 public cover previews were visually inspected; DEPT's public listing was reviewed. No gated material was accessed. Palette, typography, geometry, copy and implementation are original. Demo people, brands, quotes and figures are fictional placeholders, not sourced evidence or endorsements.

No reference photos, logos, fonts or deck files are redistributed. Templates contain replaceable image placeholders and system font stacks (Arial, Georgia and Courier New); users supply their own images. Test images are generated locally. There are no third-party visual assets requiring a redistribution license in this repository. Library licenses remain with their packages.
